# Decisiones editoriales

## 1. Base canónica

Las piezas largas que ya se publicaron como láminas o PDF se conservan como artículos independientes. La web no debe reemplazarlas por una reescritura genérica: su tesis y su voz son la referencia.

## 2. Evolución de una opinión

Hay piezas que se contradicen porque el mercado cambió: por ejemplo, una fase en la que Julián era la prioridad y otra en la que Kroupi/Tresoldi/Woltemade ganan peso. No son errores a borrar. En `Archivo → Mercado 2026/27` funcionan como diario de evolución de la planificación.

## 3. Evergreen frente a archivo

Se marca `evergreen: true` cuando la idea puede sobrevivir al mercado concreto:
- qué debe hacer el 9 del Barça;
- cómo liberar a Lamine;
- central corrector vs central constructor;
- integración de la Masia;
- coste real de un fichaje;
- rotaciones y perfiles.

Las piezas ligadas a una negociación concreta llevan `archive: mercado-2026-27`.

## 4. Hilos de X

Los grandes hilos propios se han reunido en artículos. Los borradores tienen `draft: true` para que puedas revisar si quieres mantener el formato casi cronológico o convertirlos después en una versión más literaria.

## 5. Respuestas

El archivo contiene miles de respuestas. Solo se incorporan a un artículo cuando forman parte de un hilo propio o aportan directamente a una tesis editorial ya identificada. El resto se conserva en el inventario.

## 6. Próximos PDFs e imágenes

La estructura está preparada para crecer de forma incremental. Cuando añadas una nueva pieza:
1. se busca si ya existe un artículo sobre esa tesis;
2. si existe, se usa como fuente para enriquecerlo o registrar una nueva versión;
3. si es una tesis nueva, se crea un artículo;
4. siempre se conserva la fuente original y la trazabilidad.
